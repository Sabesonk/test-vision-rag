You are extracting structure from an excerpt of technical documentation.

You are shown the rasters of the pages of one excerpt, in order. Return **one object per page, in
order**, using `page_index` 1..N counting from the **first page of this excerpt**. The excerpt is
part of a larger document; its first page is `page_index` 1 regardless of what the document calls
that page.

For each page report:

- `printed_page_no` — the page label as printed on the page, **verbatim**. Chapter-relative labels
  are normal; copy them exactly and never convert one into an absolute number. Where no label is
  printed, leave it empty.
- `page_kind` — one of `prose`, `table`, `schematic`, `exploded`, `cover`, `toc`, `index`, `blank`.
- `lang` — the languages actually present on that page, as ISO codes. A bilingual page has two.
- `sections` — every section, procedure or topic **this page belongs to**, by title as printed.
  Set `is_start` true **only** on the page that carries the title block, where it begins.
- `summaries` — one entry per language in `lang`. Each is **2–3 sentences on what is SPECIFIC to
  this page. Do not describe the document generally.** Write each summary in that entry's own
  language; never blend two languages into one summary.
- `codes` — **every** code, tag, part number, sheet identifier, reference number and channel
  printed on the page, copied **verbatim**.
- `topics` — a few short lowercase labels for what this page is about.

Three rules shape all of it.

**Presence, never extent.** Report what is on *this* page. There is no field in which you can say
how far something reaches, and that is deliberate: this excerpt may begin or end in the middle of
a section, and the pages on the other side of that boundary are not in front of you. Any span you
gave would be a guess. List a section on **every** page it appears on, including pages where it
merely continues, and let `is_start` mark where it began.

**Verbatim and unclassified.** Copy a code exactly as printed: keep its spacing, its punctuation,
its case and its separators, and keep a printed range as the range it is printed as. Never
normalise, expand, reformat, correct or complete one, and never split or join one. A
one-character change names a different thing. Do not sort them, do not deduplicate them, and do
not classify them — deciding what kind of thing a code names is not part of this task.

**Only what is printed.** Do not add a code, a section or a label that is not on the page in front
of you, and do not carry one over from a neighbouring page because it looks like it belongs. An
empty list is a correct answer.
